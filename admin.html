help Langkah Pengaturan Firebase

  1. Buka console.firebase.google.com.
  2. Pilih atau buat proyek baru (contoh: sdinpres-lelingluan).
  3. Pilih menu Firestore Database lalu klik Create Database (Pilih lokasi terdekat: asia-southeast2 Jakarta).
  4. Di menu Project Settings > General, tambahkan aplikasi Web (ikon </>) dan salin objek konfigurasi ke form di samping.
  5. Atur Security Rules agar postingan dapat dibaca dan disimpan.
Security Rules (firestore.rules) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /posts/{postId} {
      allow read: if true;
      allow write: if true;
    }
  }
}
