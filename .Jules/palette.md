## 2024-08-16 - Add Focus Visible Styles and Empty State Boxes\n**Learning:** This static landing page was completely missing global keyboard focus indicators (`:focus-visible`), meaning users navigating by keyboard couldn't easily see their active element. It also relied on a `.loading-placeholder-box` class in JS that wasn't defined in CSS, resulting in poor unstyled empty states for failed API calls.\n**Action:** Always verify a global `:focus-visible` outline exists in reset or base styles. Always check that dynamically injected CSS classes via JS are actually present in the stylesheet.
